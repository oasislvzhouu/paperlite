# 随包字体与许可

PaperLite 内置以下字体（供「阅读设置 → 字体」选择），均为可自由分发的开源字体。
字体文件随应用打包，不联网加载。

| 字体 | 文件 | 许可 |
|---|---|---|
| EB Garamond | `EBGaramond-Regular.otf` / `EBGaramond-Italic.otf` | SIL Open Font License 1.1 |
| Linux Libertine | `LinuxLibertine-Regular.otf` / `LinuxLibertine-Italic.otf` | SIL Open Font License 1.1 / GPL（双许可） |
| Lato | `Lato-Regular.ttf` / `Lato-Bold.ttf` / `Lato-Italic.ttf` | SIL Open Font License 1.1 |
| Open Sans | `OpenSans-Variable.ttf` | Apache License 2.0 |

## SIL OFL 1.1 要点

- 允许自由使用、复制、合并、发布、分发与修改字体。
- 修改后的版本不得再使用原保留字体名（Reserved Font Name）。
- 分发时必须随附本许可声明与版权声明。
- 字体不得单独售卖。

原文见 <https://scripts.sil.org/OFL>。
